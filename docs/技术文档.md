## 1. 系统概述

### 1.1 做什么

输入一个人的数据（体检化验、血压、体格、可穿戴、CGM、家庭血压、生活方式、基因、甲基化），输出一份单文件 HTML 报告，包含：

| 报告内容 | 由谁计算 |
|---|---|
| LongPi Age（死亡风险等效年龄）及 80% 区间、瀑布图拆解 | 引擎 |
| 120 指数（三种情景及加权）、里程碑概率、期望寿命、生存曲线 | 引擎 |
| PhenoAge 轨迹、LongPi Age 历年快照、LongPi Pace | 引擎 |
| 干预预测（ΔLongPi Age、获益概率、Δ120 指数）、核心方案 | 引擎 |
| 补测清单与数据完整度（补哪一项、区间能窄多少） | 引擎 |
| China-PAR、eGFR、FIB-4 等临床指标 | 引擎（`clinical.py`） |
| 数据图表（睡眠、心率、步数、CGM、化验趋势、数据覆盖） | `derive.py` |
| 风险卡、药物基因组卡、前沿分析卡、数据质量说明、N-of-1 设计、总结 | Claude 写 narrative.json |

### 1.3 数据流

```
person.json ──check──▶ 输入检查（schema.check）
     │
     ├──derive──▶ 化验换算到规范单位（就地修改）、可穿戴摘要 wearables{}、图表数据 data{}
     │
     └──run──▶ Model：collect_inputs → 每个领域一个输入值
                       phenoage_points → 卡尔曼 → 当前 PhenoAge 差值后验
                       2000 次抽样：参数、测量误差、设备偏差、未测领域、人群均值偏移、s²
                       → ln R、各领域贡献；干预与核心方案（共用随机数）
              summarise：E[R] 点估计 → LongPi Age；三情景生存 → 120 指数；干预汇总
              trajectory：每次体检日的快照 → LongPi Pace
              data_value：补测清单与数据完整度
              clinical.summary：临床指标
     ▼
results.json ──facts──▶ 事实表（Claude 写叙述用）
     │
     └── + narrative.json ──render──▶ report.html（叙述先过 check_narrative）
```

### 1.4 运行方式与性能

| 命令 | 作用 | 返回码 |
|---|---|---|
| `python3 scripts/longpi_report.py check person.json` | 输入检查，打印 errors / warnings / missing | 有 errors 时为 2 |
| `… compute person.json -o results.json [--draws 2000] [--seed 20261024]` | derive + run，写 results.json（含 data、wearables、checks） | 有 errors 时为 2 |
| `… facts results.json` | 打印事实表 | 0 |
| `… render results.json narrative.json -o report.html [--strict]` | 叙述检查后渲染；`--strict` 时叙述有问题就为 2；results 来自旧版引擎时为 2（需重新 compute） | 0 / 2 |
| `… demo -o DIR [--draws 1500]` | 演示用户端到端 | 0 / 2 |

- 运行环境：Python 3.9+ 标准库，不联网。
- 工作文件夹：个人资料和产出放在 Skill 目录以外的文件夹里，脚本用绝对路径调用（SKILL.md）；Apple 导出的缓存写在导出文件旁边。
- 耗时：演示用户约 29 秒（M1，机器空闲时；负载高时 3–4 分钟）。主抽样 2,000 次，4 次历史快照各 300 次，补测清单每个假设 500 次（演示用户共 7 组：现在、4 项、全部做完、只知道年龄性别）。
- 随机性：主抽样用 `random.Random(seed)`，干预用 `seed + 1`，快照用 `1000 + i`，补测清单用固定种子 7，甲基化残差的预跑用种子 97。同一输入、同一种子结果完全可复现。

## 2. 输入

### 2.1 person.json 字段与使用位置

完整格式和示例见 `references/input_schema.md` 与 `examples/demo_person.json`。

| 字段 | 用在哪里 |
|---|---|
| `as_of` | 计算日期：年龄、时间窗口、情景起点（`Model.__init__`） |
| `person.sex`、`person.birth` 或 `person.age` | 性别、年龄（`age` 优先；否则 `(as_of − birth)/365.25`） |
| `person.region.urban / north` | 吸烟 RR 的城乡版本（`Model.region`）；China-PAR 的城乡、南北项 |
| `labs[]` | PhenoAge（同一天九项齐全）；LDL；HbA1c 与空腹血糖；临床计算器；化验趋势图 |
| `vitals[]`（`setting: "office"`） | 无家庭血压时的收缩压（2 年内最近 ≤2 次均值）；无手表时的静息心率（`pulse`）；收缩压趋势图 |
| `anthropometrics[]` | BMI（2 年内最近一次的 `bmi` 字段；没有则用 2 年内最近一次的身高体重现算）；腰围（China-PAR、中心型肥胖） |
| `fitness[]` | VO2max（`method: "cpet"` 优先，3 年内）；握力 `grip_kg`（3 年内） |
| `lifestyle.smoking` | 吸烟分级（§2.5） |
| `lifestyle.alcohol` | `grams_per_week` 或 `grams_per_day`（×7） |
| `lifestyle.sleep_h` | 无手表睡眠时的问卷睡眠 |
| `conditions[]` | 名称含"糖尿病"且不含"前期"→ 视为糖尿病；China-PAR 的糖尿病项 |
| `medications[]` | 名称含"降压"或 `class: "antihypertensive"` → China-PAR 的"治疗中"项 |
| `family_history[]` | China-PAR 家族史（含"冠心病""心梗""卒中""脑梗"才算） |
| `methylation[]` | `clock_type` 为 GrimAge2 / GrimAge 且有数值、3 年内的结果计入 LongPi Age（§6.6）；其余（第一代、器官年龄等）只在前沿页展示 |
| `genetics`、`imaging`、`other_tests`、`meals` | genetics/imaging/other_tests 供叙述使用；`meals` 用于 CGM 餐后峰值 |
| `wearables.{apple_health_xml, daily_csv, cgm_csv, bp_csv, device}` | §2.4；`device` 决定 VO2max 校正方式 |
| `synthetic` | 为 true 时报告加演示横幅 |

### 2.3 输入检查（`schema.check`）

- **报错**（errors，阻止计算）：
  - 性别不是 M/F；
  - 既没有 `age` 也没有 `birth`，或缺 `as_of`；
  - 日期无法解析；
  - 表内化验项的单位无法换算；
  - `wearables` 指向的文件不存在。
- **警告**（warnings）：
  - 年龄不在 30–85 岁；
  - 换算后的数值超出下表范围；
  - 甲基化 `clock_type` 不认识（按不计入处理），或写了 GrimAge2 / GrimAge 却没有数值。
- **缺失提示**（missing）：
  - 没有一次九项齐全（允许缺 CRP）的血液检测；
  - 缺 hs-CRP；
  - 缺吸烟史；
  - 既没有 VO2max 也没有可穿戴文件；
  - 缺握力。

## 3. 参考死亡率（`mortality.py`）

### 3.1 数据

`data/lifetable_china_wpp2024.json` 由 `evidence/scripts/build_lifetables.py` 生成：
- 来源：WPP 2024 complete life tables（medium variant），LocID 156。
- 内容：2000–2100 年、男女、0–100 岁（100 为 100+ 开区间）的 mx，以及 e0。
- 年份：2023 年及以前为估计值，2024 年起为预测值。

### 3.2 年死亡率 μ(age, year)（`Reference.mu_period`）

- 年份先截到 [2000, 2100]。
- 年龄 ≤91：WPP mx。
- 年龄 ≥96：Gamma-Gompertz 曲线 `μ(x) = a·e^{b(x−80)} / (1 + (a·s²/b)(e^{b(x−80)} − 1))`，其中 s² = b / 平台。
- 92–95 岁：对数尺度线性过渡，权重 (age − 91)/5。
- 年份 >2100：再乘以 `exp(r_after[min(age,100)] × (year − 2100))`。`r_after` 为 2090→2100 年各年龄的年均对数变化。
- 小数年龄（`mu_at`）：相邻两个整岁之间在对数尺度上线性插值。

### 3.3 极高龄拟合（`Reference._old_fit`）

- 目标：在 `old_age.fit_ages`（60–94 岁）上，使 Σ(ln μ_模型 − ln mx_WPP)² 最小；平台固定为 0.70。
- 算法：
  1. 网格搜索：b ∈ {0.040, 0.044, …, 0.180}，a = mx(80) × {0.01, …, 3.99}；
  2. 坐标下降：a 的初始步长为 a × 5%，b 为 0.002；某一轮四个方向都无改进时，两个步长同时减半，共 60 轮。
- 结果按年份缓存；s² 只用于外推曲线本身。个人脆弱性使用的 s² 另取 `frailty.s2`（§7）。

### 3.4 Gompertz 斜率 b（`gompertz_slope`）

计算年份（as_of 所在年）35–90 岁的 ln μ 对年龄做最小二乘斜率。LongPi Age 的换算只用这个 b。

### 3.5 情景下的队列路径（`cohort_hazards`）

一个 age0 岁、处于 year0 年的人，在年龄 x 时所处的日历年 = round(year0 + x − age0)。

| kind | 年龄 x 的 μ |
|---|---|
| `period` | μ(x, ⌊year0⌋)，冻结在当年 |
| `wpp` | μ(x, 对应日历年) |
| `wpp_slowed` | 先算 d = slope_reduction × min(1, max(0, (年 − start_year)/ramp_years))。x ≤ pivot_age 时取 μ(x, 年)；否则取 μ_at(pivot + (x − pivot)(1 − d), 年) |
| `wpp_plus`（保留，未使用） | μ(x, 年) × (1 − extra_rate)^(年 − start_year)，仅对 x ≥ min_age |

### 3.6 生存、期望寿命、概率

- `survival_from`：从 age0 起逐岁累乘 exp(−μ)。第一个不足整岁的区间按 (1 − 小数部分) 计，得到 age0、⌊age0⌋+1 … 130 岁各点的生存率。
- `individual_survival`：`S_你(x) = [1 + R·(S_参考(x)^(−s²) − 1)]^(−1/s²)`（§7.2）。
- `at_age`：在相邻两点之间对 ln S 线性插值。
- `life_expectancy`：age0 加上生存曲线下面积（梯形法），截止 130 岁。

### 4.1 PhenoAge

```
xb = −19.90667 + 0.08035356·age − 0.03359355·白蛋白(g/L) + 0.009506491·肌酐(μmol/L) + 0.1953192·血糖(mmol/L)
     + 0.09536762·ln(CRP mg/dL) − 0.01199984·淋巴细胞% + 0.02676401·MCV(fL) + 0.3306156·RDW(%)
     + 0.001868778·ALP(U/L) + 0.05542406·WBC(10^9/L)
M  = 1 − exp(−1.51714·exp(xb) / 0.007692696)
PhenoAge = 141.50225 + ln(−0.0055305·ln(1 − M)) / 0.090165  = 141.50225 + (0.08679 + xb) / 0.090165
```

- 系数和常数与 BioAge `phenoage_calc(orig = TRUE)` 一致，测试 `test_matches_bioage_phenoage_calc` 逐位核对。

- CRP 的规范单位是 mg/L，进入公式前除以 10 换成 mg/dL；低于 0.1 mg/L 按 0.1 计。
- 没有 hs-CRP 时：按 `clock.crp_impute_mg_l`（1.0 mg/L）补入，这次测量的噪声方差另加 `crp_impute_extra_var`（1.1 年²）。

### 4.4 多次检测合并（`kalman_gap`）

采用局部水平模型：
- 先验：均值 0，方差 = max(同龄差值 SD² − 各次噪声方差的均值, 1)。
- 两次检测之间方差增加 q × Δt，q = 0.8 年²/年。
- 每次检测做标准卡尔曼更新：K = P/(P + r)。
- 最后一次检测到计算日之间再加 q × Δt。

输出当前差值的后验均值与 SD。蒙特卡洛中每次抽样 G ~ N(均值, SD²)。

### 4.5 差值的风险换算 g(G)（`gap_loghr`）

分段线性：G < −5 时为 s中·(−5) + s低·(G + 5)；−5 ≤ G ≤ 5 时为 s中·G；G > 5 时为 s中·5 + s高·(G − 5)。三个斜率和它们的 SE 见 §6.2，每次抽样按 N(估计值, SE²) 抽取。

### 4.6a 异常期的血液检查（`clock.analyte_flags`、`engine.clock_alternative`）

- 自动标记（`params.json: clock.flags`）：hs-CRP > 10 mg/L 为急性炎症（CDC/AHA 2003 建议病后复查）；MCV 不在 82–100 fL（WS/T 405-2012）或 RDW-CV > 15.5% 为红细胞异常。
- `labs[].clock_exclude`：`true` 整次不计入；列表（如 `["mcv","rdw"]`）只去掉这些分析物，用 `data_menu.typical_blood` 代替，并把（每单位年数 × NHANES 人群 SD）² 加进这次的噪声方差（`clock.analyte_pop_sd`）。
- 主结果只按用户确认的 `clock_exclude` 计算。有标记时 `run` 另算一份 `clock_alternative`：急性炎症整次不计入、红细胞异常去掉 MCV/RDW，800 次抽样（种子 seed+7），给出点估计、80% 区间和与主结果之差，报告首页大数字下方提示。
- 真实病例核对：贫血恢复期一次（MCV 65、RDW 19）与另一次（MCV 76）被标记，处理后 28.9 → 24.7 岁，与人工敏感性分析一致。

## 5. 功能领域（`domains.py`）

### 5.1 形状与归一化

- 先按 `clip` 截断 x。
- `loglinear`：f = β·x，β = ln RR / per。
- `hinge`：f = b低·max(0, k低 − x) + b高·max(0, x − k高)，两个拐点之间为平。
- `categorical`：f = ln RR[类别]。
  - `levels` 是个人类别；城乡由 `levels_by_region` 覆盖。
  - `pop_levels` 是人群类别，用于归一化，也用于类别未知的人（值写作 `pop:<类别>`）。
  - 两套里规格相同的类别共用同一次抽样。
- `norm_kind: "categorical_mid"`（饮酒）：个人取连续克数，人群按类别占比 × 类别中点归一化。
- **归一化**：l(x) = f(x) − ln E_pop[exp f(X)]，X 取同龄同性别中国人分布，所以人群平均风险比恰好为 1。
  - loglinear 且 clip 不落在 μ ± 4SD 以内：用解析式 βμ + ½β²σ²；
  - 其余连续情形：用 20 点 Gauss-Hermite，结果按参数缓存；
  - 分类情形：Σ p·RR。
- **参数抽样**（`draw_log_rr`）：ln RR ~ N(ln 点值, SE²)，SE = (ln 上限 − ln 下限)/(2 × 1.959964)。
- **人群均值偏移**：人群分布带 `mean_se` 的领域（目前只有 vo2max，±2.5），每次抽样再抽一个偏移量，同时作用于归一化和未测时的人群抽样。
- **未测领域**：每次抽样从人群分布抽一个值（连续为正态，分类按占比，饮酒取类别中点）。

## 6. 合成：LongPi Age（`engine.Model`、`summarise`）

### 6.1 公式

```
ln R = 时钟项 + Σ_d c_d · l_d(x_d) + 甲基化项
       时钟项：有血检时 g(G)；没有时 r_c ~ N(−σ_c²/2, σ_c²)，且系数用 without_clock 组（§4.6）
       甲基化项：β·M − β²σ_M²/2；没测时 M ~ N(0, σ_M²)，测了 GrimAge2 / GrimAge 时 M 取收缩后的后验（§6.6）
LongPi Age = 年龄 + ln E[R] / b            E[R] 为全部抽样 exp(ln R) 的均值
```

### 6.3 每次抽样抽什么（`Model.draw`）

| 量 | 分布 |
|---|---|
| 每个领域的剂量反应参数 | ln RR ~ N(ln 点值, SE²)（§5.1） |
| 每个领域的系数 c_d | 抽标准正态 zc，`log_r` 里按当前系数组算 value + zc·sd（换系数组时同一个 zc 可复用） |
| 人群均值偏移 | N(0, mean_se²)（仅 vo2max） |
| 已测连续领域的"真值" | 测量值 + N(偏差, 偏差SD²) + N(0, 随机SD²)；饮酒截断在 ≥0 |
| 已测分类领域 | 固定 |
| 未测领域 | 人群分布（加偏移） |
| 时钟三段斜率 | N(估计值, SE²) |
| s² | N(0.16, 0.03²)，截断在 [0.06, 0.35] |
| 当前 PhenoAge 差值 G | 抽标准正态 zG，G = 后验均值 + zG·后验SD |
| 没有血检时的残差 r_c | 抽标准正态 zr（§4.6） |
| 甲基化残差 | 抽标准正态 zm；系数 β ~ N(β̂, SE²)（§6.6） |
| 补测假设用的测量噪声 | 每个领域再抽一个标准正态 zx，只在补测清单里用 |

所有标准正态每次都抽，与是否用到无关，所以补测清单的各个假设可以复用同一组抽样（共同随机数）。

### 6.4 点估计与区间

- LongPi Age 点估计：年龄 + ln E[R]/b。区间取 2,000 次 `年龄 + ln R/b` 的第 10、90 百分位。
- 各领域"年数"：点估计为 ln E[exp(该领域贡献)]/b，区间取该领域贡献/b 的分位数。由于对数与期望不能交换次序，各领域点估计之和与总差值会有小差别。
- `results.json` 中 `median` 字段存的是上述点估计（沿用 Demo 的字段名），`p10`、`p90` 才是分位数。
- `clock_delta`、`methylation_delta` 分别是时钟项、甲基化项的点估计；`function_delta` = 总差值 − 两者。
- 报告瀑布图里没测的行（含没有血检时的时钟行、没有 GrimAge2 时的甲基化行）只显示"未测"，不显示数值：它们的点估计按构造为 0，显示出来的只是抽样误差。

### 6.6 甲基化层（`methylation_input`、`Model.meth_term`）

1. **选结果**：`clock_type` 为 GrimAge2 或 GrimAge、有 `bio_age`、采样日在计算日之前 3 年内；同日两者都有时取 GrimAge2。
2. **加速**：A = 时钟值 − (a + b·采样时年龄)，a、b 为 NHANES 按性别的加权线性参考。
3. **残差**：M_obs = A − E[A | LP, 年龄, 性别]。
   - LP 用这个人不含甲基化的点估计 ln E[R]。
   - LP 由 `_set_methylation_residual` 先跑 400 次抽样得到，种子 97。
4. **收缩**：k = σ_M² /（σ_M² + s_lab² + s_pop²），M ~ N(k·M_obs, k·(s_lab² + s_pop²))。
5. **计入项**：β·M − β²σ_M²/2。
   - 没测时 M ~ N(0, σ_M²)，所以人群平均风险为 1。
   - 测得 M_obs = 0 的人会得到略小于 0 的计入项。原因：中位数低于均值（对数正态），这与功能领域的处理一致。

### 7.2 计算步骤

1. `Model.__init__` 对每个情景算一次参考生存曲线 S_参考（age0 起，到 130 岁），整个运行中固定不变。平台只用点值 0.70，不随抽样变化。
2. 个人生存曲线由 Gamma 脆弱性恒等式得到：`S_你(x) = [1 + R·(S_参考(x)^(−s²) − 1)]^(−1/s²)`。
   - R = 1 时与参考曲线重合；
   - 起始年龄处风险比为 R；
   - 极高龄时风险比趋向 1（测试 `test_hazard_ratio_attenuates_at_extreme_age`）。
3. 点估计：R = E[R]，s² = 全部抽样 s² 的均值。区间：每隔 ⌊抽样数/600⌋ 个取一个（2,000 次抽样时每 3 个取 1 个，共 667 个），各自用自己的 R 和 s² 计算。
4. 每个情景的输出：
   - 120 指数 = 100 + 10·log10(P你(120)/P参考(120))，P 截断在 ≥1e−300；
   - 80/90/100/110/120 岁里程碑概率；
   - 期望寿命；
   - 曲线：点估计曲线、按年龄的 p10/p90、参考曲线。
5. 加权指数：点估计 = Σ 权重 × 各情景点估计；区间 = 每个子样本的加权指数取分位数。

## 8. LongPi Pace 与历年轨迹（`engine.trajectory`）

1. 对每个有 PhenoAge 的体检日 d，构造 `Model(at=d, snapshot=True, n_draws=300, seed=1000+i)`。只用当天及以前的体检类数据，不用可穿戴数据（§2.5）。快照差值 = ln E[R]/b；`sd` 为 300 次抽样的标准差，包含未测领域的人群分布，所以每年数值相近。
2. 图上的阴影用 `pace.obs_sd_years`（1.6 年）表示单次快照的测量波动。这个值由 PhenoAge 生物学变异、单次诊室血压和 LDL 变异推算。
3. Pace = 1 + 斜率。斜率来自贝叶斯直线回归（`clock.trend_posterior`）：
   - 截距先验 N(0, 8²)，斜率先验 N(0, 0.29²)（Dunedin Pace of Aging 的人群 SD）；
   - 每点方差 1.6²；
   - 输出后验均值和 SD，再给出 80% 区间。
4. 信息增益 = 1 − 后验SD/先验SD，后验 SD 按 (1/0.29² + Σ(t − t̄)²/1.6²)^(−1/2) 计算。至少 4 次且信息增益 ≥0.2 才报告（status = reported）。
5. `more_annual_tests_needed`：在现有体检时间之后每年加一次，数到信息增益 ≥0.2 为止，最多 30 次。

## 9. 干预预测（`engine.intervention_effect`、`summarise`）

### 9.1 规格字段（`params.json: interventions[]`）

| 字段 | 含义 |
|---|---|
| `effects[]` | 四种：① 加性 `{domain, mean, sd, floor?, ceiling?}`：x → x + f·N(mean, sd²)；② 相对 `relative: true`：x → x·(1 + f·N(mean, sd²))；③ `set`：f ≥ 0.5 时把类别设为指定值；④ `type: "direct"`：ln R 直接加 f·N(ln RR, SE²) |
| `floor` / `ceiling` | 原值在下限之上时，改变后不低于下限；上限同理 |
| `when` | 适用条件：领域缺失时默认不适用（`require_measured` 默认 true）；`in`、`min`、`max` 作用于 `collect_inputs` 选出的值（血压为诊室口径，睡眠为问卷口径） |
| `adherence`、`adherence_kind` | `bernoulli`：f ∈ {0,1}，P(f=1) = adherence；`fraction`（默认）：f ~ Beta(a·k, (1−a)·k)，k = 4，均值 a |
| `core` | 是否计入核心方案 |
| `medical` | 处方药（显示 ⚕、"需医生决定"，不进"三件事"） |
| `evidence` | A/B/C 给数值；D 不给 |

### 9.2 计算

- 每次抽样用同一组 θ（共用随机数），对每个适用的干预分别抽依从性和效应，得到改变后的 ln R。
- 核心方案在同一次抽样里叠加所有 `core` 干预：同一领域的变换依次复合，direct 项相加。
- 汇总：
  - `d_longpi_age`：点估计 = [ln E(R_改变后) − ln E(R)]/b，已含依从性；区间为逐次差值的分位数。
  - `p_benefit`：逐次差值 ≤ −0.1 年的比例。
  - `d_index_central` / `d_life_exp_central`：中心情景下，用两个 E[R] 分别计算后的差值。
  - `small_effect`：点估计 > −0.05 年且获益概率 <0.2，报告中隐藏。
- 报告"本季度三件事"：narrative 没有给 `top3` 时，从非处方、可量化、未隐藏（非 `small_effect`）的干预里按点估计取前三（模板 `renderOverview`）。

## 10. 补测清单与数据完整度（`engine.data_value`）

**候选项**（`_actions`）：
- 没有血检：`blood_panel`。九项里含空腹血糖，所以没测血糖领域时同时补上。
- 有血检：最近一次缺 CRP 时加 `hs_crp`；再加 `blood_repeat`。
- 甲基化没计入：`methylation`。现状写"未做"，或"已做，但报告里没有 GrimAge2 / GrimAge"。
- 每个未测领域：`dom:<id>`。
- 手表估算的心肺：`dom:crf`，换成 CPET。
- 只有体检血压或体检脉搏：`dom:bp` / `dom:rhr`，换成家庭血压或手表。手表静息心率和手表睡眠没有更好的常规方法，不列。

**每项怎么"做"**：
- `patch` 改模型状态：
  - 抽血：有时钟 + with_clock 系数 + 一次典型噪声的后验；
  - hs-CRP：去掉最近一次的补入方差后重算卡尔曼；
  - 再抽一次：在计算日加一次同样噪声的观测；
  - 甲基化：M_obs = 0。
- `mod` 改单次抽样里的领域值：未测取典型值（连续取人群均值 + 本次人群偏移，分类取占比最大的类别）；设备值去掉偏差；再加该方法本身的误差 zx·after_sd。

**宽度**：`_width` 每次都重置种子 7、抽 500 次，返回第 90 与第 10 百分位之差。所以"现在"、"做了某项"、"全部做完"用的是同一组抽样。

**汇总**：
- `width_none` 用只有年龄、性别的 Model 算；
- 数据完整度 =（width_none − width_now）/（width_none − width_all），截在 0–100；
- 收窄 < 0.1 年的项目进 `small_items`，不展示；
- `other_uses` 列出不改变 LongPi Age 的数据，并标记是否已有。

### 12.2 叙述检查（`schema.check_narrative`）

**nhanes_build.py**
- 周期 1999–2017，共 10 个。按候选名单统一变量名，因为不同周期名字不同，例如 ALP 有 `LBXSAPSI` / `LBDSAPSI`，HDL 有 `LBDHDD` / `LBXHDD` / `LBDHDL`。
- 死亡随访文件是定宽格式：SEQN 第 1–6 列，ELIGSTAT 第 15 列，MORTSTAT 第 16 列，UCOD 第 17–19 列，PERMTH_EXM 第 46–48 列；`.` 视为缺失。
- 纳入：年龄 ≥20、ELIGSTAT = 1、有随访月数、非孕。
- 权重：1999–2002 用 4 年权重 × 2/10，其余用 2 年权重 × 1/10（NCHS 合并规则）。
- 收缩压：最多 4 次读数的均值，0 视为缺失。
- CRP 统一为 mg/dL：2015–2018 的 hs-CRP 是 mg/L，除以 10。
- 吸烟：SMQ020/SMQ040 → 从不、已戒、现吸。

**nhanes_calibration.py**
1. 用 NHANES 自己的加权分布作"同龄人"（性别 × 7 个年龄段），调用 Skill 的 `domains.py` 计算每人每个领域的 l。吸烟按人群 RR（`pop:` 类别），血糖按 HbA1c 和自报糖尿病分 ADA 三级。
2. 时钟分段项：g_lo = min(G + 5, 0)，g_mid = clip(G, −5, 5)，g_hi = max(G − 5, 0)。
3. 可迁移性检验：每个领域单独做 Cox（年龄 + 性别 + l），以及再加入时钟三段。
4. 联合模型：
   - 年龄 + 性别 + 时钟三段 + 核心五领域（bp、rhr、adiposity、glucose、smoking）；
   - 睡眠另加一个模型（2005 年以后的周期）；
   - LDL 用空腹子样本，心肺用 1999–2004，握力用 2011–2014（这两个周期没有 CRP）；
   - 无时钟版本去掉时钟项。
5. 系数规则见 §6.2。
6. 时间外推验证：用 1999–2007 周期（数据年份 1999–2008）重估全部系数，在 2009–2017 周期（数据年份 2009–2018）上检验。LongPi 差值 = 线性预测值 / 年龄系数，未测领域记为 0；同时计算十分位校准、Demo 拼法和 PhenoAge 1:1 对照。

### 16.3 已知的模型简化

1. **校准人群**：用的是美国 NHANES，没有中国个体级验证；可迁移性检验（§15.1）显示血压偏弱、观察性 LDL 为负，处理方式见 §6.2。
2. **PhenoAge 文献 HR 复现不一致**：Levine/Liu 报告每岁 1.09，本流程按其样本设定复现得到 1.054。原因无法从公开材料确定；本模型使用自己在公共数据上可复现的估计。
3. **未测领域独立抽样**，忽略领域间相关，区间偏宽。
4. **平台不确定性没有传播**：参考生存曲线只用平台点值；只有个人脆弱性的 s² 随抽样变化。
5. **2100 年前后不一致**：2100 年以前 96 岁以上的平台固定为 0.70，2100 年以后随 WPP 100+ 岁的改善速度下降。
6. **情景年份取整**：日历年 = round(year0 + x − age0)，最多有半年偏差。
7. **快照的生活方式不分时期**：饮酒和问卷睡眠按当前值套用到过去；吸烟按戒烟年份处理。
8. **干预没有时间动态**：按"指标变化达成后的稳态"计算，不模拟起效过程和长期衰减。
9. **字段命名**：`median` 字段存的是点估计（§6.4）。
10. **"三件事"的选取**只按预期效果排序，没有综合考虑获益概率与执行难度。
11. **期望寿命截止在 130 岁**（130 岁时生存概率可以忽略）。
12. **甲基化残差相对 LongPi 点估计**，而不是每次抽样的值：不假设甲基化能替代其他指标。偏保守：NHANES 里 GrimAge2 只能替代缺失血检的 7%。
13. **甲基化只在 50 岁以上校准**，30–49 岁是外推；DunedinPACE 没有公开的死亡随访数据，暂不计入。
14. **补测假设取"典型结果"**，没有对所有可能结果求平均；对加性的对数风险，宽度几乎不受取值影响。
15. **没有血检时的残差与甲基化残差按独立处理**。
