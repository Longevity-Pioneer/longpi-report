# 药物基因组卡

依据：CPIC（Clinical Pharmacogenetics Implementation Consortium）指南。每条写成"基因 结果（表型）：对什么药有什么影响，就医时怎么做"。
消费级芯片可能有假阳性，**重要处方前应在医院复核**；不建议自行停药或换药。

| 基因 | 常见报告结果 | 相关药物 | 写法要点 |
|---|---|---|---|
| CYP2C19 | *1/*2、*2/*2、*2/*3（中间/慢代谢型）；*17（快代谢） | 氯吡格雷；部分 PPI、SSRI、伏立康唑 | 中间或慢代谢型：氯吡格雷活性代谢物减少，冠脉支架或急性冠脉综合征需要抗血小板时，提醒医生考虑替格瑞洛等替代药 |
| SLCO1B1 | rs4149056 TC（功能降低）、CC（功能差） | 他汀，尤其辛伐他汀 | 功能降低：避免辛伐他汀 >20 mg/天，或换用其他他汀；功能差：避免辛伐他汀。其他他汀按指南剂量 |
| CYP2C9 + VKORC1 | CYP2C9 *2/*3；VKORC1 −1639 G>A | 华法林 | 需要用华法林时按基因型剂量算法起始；东亚人群 VKORC1 A 等位常见，所需剂量偏低 |
| HLA-B*58:01 | 携带 | 别嘌醇 | 携带者禁用别嘌醇（严重皮肤不良反应风险高）；汉族人群并不少见，痛风或高尿酸需要降尿酸药时一定告诉医生 |
| HLA-B*15:02 | 携带 | 卡马西平、奥卡西平 | 携带者避免首次使用（Stevens-Johnson 综合征风险）；中国南方人群较常见 |
| CYP2D6 | 慢代谢 / 超快代谢 | 可待因、曲马多；他莫昔芬 | 慢代谢：可待因、曲马多止痛效果差；超快代谢：中毒风险，两者都应避免可待因。用他莫昔芬时需告知肿瘤科 |
| DPYD | 活性降低 | 氟尿嘧啶类（5-FU、卡培他滨） | 化疗前必须告知肿瘤科，需减量或换药 |
| TPMT / NUDT15 | 中间/慢代谢 | 硫唑嘌呤、巯嘌呤 | 需大幅减量或换药；NUDT15 变异在东亚人群常见 |
| UGT1A1 | *28、*6 | 伊立替康；阿扎那韦 | *6 在东亚人群常见；用伊立替康前告知肿瘤科 |
| ALDH2 | rs671 GA/AA（*2 携带） | 酒精（不是 CPIC 药物） | 喝酒脸红；携带者饮酒显著增加食管癌风险，建议不喝酒 |

不要写进药物基因组卡的：MTHFR（不指导常规补充剂）、APOE（无症状人群不用于临床决策，若用户问再单独、谨慎解释）、
各种"营养代谢型"位点（证据弱，最多放进前沿卡并标"探索"）。
