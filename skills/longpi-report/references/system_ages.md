# 系统 LongPi Age（引擎 1.1.1）

`results.json` 新增 `system_ages`：把全身 LongPi Age 的各项按身体系统重新归组。**没有新的效应量，没有新的拟合，也不改变全身数值。**

## 公式

全身：`log R = g(G) + Σ c_d·l_d + 甲基化项`，`LongPi Age = 年龄 + ln E[R] / b`。

系统：`系统 LongPi Age = 年龄 + ln E[exp(Σ 属于该系统的项)] / b`，80% 区间取同一批抽样的第 10–90 百分位。

- **领域项**：十个领域的 `c_d·l_d`，与全身数值用的是同一个数（同一文献剂量反应、同一中国人群归一化、同一系数）。
- **血液时钟分项**：PhenoAge 对九项化验是线性的，每项使 PhenoAge 变化“系数 ÷ 0.090165”岁，所以差值 G 可以精确拆成九项
  各自相对同龄同性别参考值（`data/phenoage_analyte_reference.json`，与 PhenoAge 参考曲线同一样本、同一平滑方法）的偏离。
  多次检测的滤波对各次差值是线性的，每一项有自己的滤波份额 m_k，合计等于 G。对数风险 g(G) 是分段线性的：第 k 项取
  `g(G)/G × m_k`；时钟项的不确定度按各项的测量噪声份额分摊。
- **归属**：领域按 `data/systems.json`；化验项目按 Levine 2018 表 1 自己印的系统标签（白蛋白、ALP—肝；肌酐—肾；葡萄糖—代谢；
  CRP—炎症；淋巴细胞百分比、MCV、RDW、白细胞—免疫）。吸烟、饮酒是全因死亡的效应量，不归入单一系统。
- **恒等式**：每一次抽样里，各系统的项 + 吸烟 + 饮酒 + 未分配余项 + 甲基化项 = 全身 log R（`consistency.max_abs_log_hazard_error`）。
  点估计用 E[R]，所以各系统的“岁数”相加只是近似等于全身差值。

## 读结果时要知道的四件事

1. 这些是**按系统归组的风险等效年龄**，由已发表的关联换算而来；**没有单独做过回测**；不是诊断，也不是器官的生理年龄。
2. 有九项血检时，引擎换用“有血液时钟”的系数：血糖、BMI 两个领域的系数降到约 0.03，血糖的信息改由“葡萄糖”分项承担。
3. g(G) 分段线性：同一项化验折成多少岁，取决于整体差值落在哪一段（差值超过 +5 岁后每岁的折算变小）。
4. 系统区间只含该系统各项的测量与参数不确定度，不含“归组是否恰当”的不确定度；化验类系统的区间因此很窄，展示时不要当作精度。

## 尚不能估计

- 没有九项血检：肾、肝、免疫与炎症尚不能估计（只有肌酐不够：PhenoAge 需要其余八项才能算出差值）；全身模型里
  “看不到的那一块”不分到任何系统。CRP 未测或某项按 `clock_exclude` 剔除时，该项标为未实测。
- 没有 VO2max / 握力 / 睡眠时长：对应系统尚不能估计。肠道没有任何可换算的项。
- 各系统“暂不计入”的指标及原因见 `data/systems.json: not_counted`。

## 厂商甲基化器官年龄

规则只有一条（`data/systems.json: methylation_organ`）：作为单独的佐证行显示，不改变系统年龄；厂商差值 = 器官年龄 − **采样时**的
日历年龄；与系统差值相差超过 2×s_lab（4.8 岁）时标为“不一致”。理由：厂商算法未公开，没有与结局的校准，无法放到同一尺度上加权。
